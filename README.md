# live-weather-app

## Overview
A real-time weather web application built with 
Python Flask and OpenWeatherMap API. Search any 
city worldwide and get instant weather data!

## Features
- 🌡️ Live temperature and feels-like
- 💧 Humidity percentage
- 💨 Wind speed
- ⛅ Weather condition with icon
- 🎨 Beautiful dark glassmorphism UI
- 🌍 Works for any city worldwide!

## Tools Used
Python • Flask • OpenWeatherMap API • HTML • CSS

## How to Run
1. Install requirements:
   pip install flask requests
2. Run the app:
   python app.py
3. Open browser:
   http://127.0.0.1:5000
